Privacy Policy / プライバシーポリシー

Last updated / 最終更新日: 2026-10-31

This Privacy Policy describes how niji-clip-uploader ("the Tool"), an internal tool operated by the owner of the YouTube channel "NIJI-UP-チャンネル [にじさんじ切り抜き]", handles data.

本ポリシーは、YouTubeチャンネル「NIJI-UP-チャンネル [にじさんじ切り抜き]」の運営者が使用する内部ツール niji-clip-uploader（以下「本ツール」）におけるデータの取り扱いを定めるものです。

1. Use of YouTube API Services / YouTube API サービスの利用

The Tool uses YouTube API Services. By using the Tool, the user agrees to be bound by the YouTube Terms of Service. The Google Privacy Policy also applies.

本ツールは YouTube API サービスを使用しています。本ツールの利用者は YouTube 利用規約 に同意したものとみなされます。また Google プライバシーポリシー が適用されます。

2. Who uses the Tool / 利用者

The Tool is used only by the channel owner. It does not collect data from any other users or viewers.

本ツールの利用者はチャンネル運営者本人のみです。他のユーザーや視聴者からデータを収集することはありません。

3. Data accessed / 取得するデータ

  • OAuth access and refresh tokens for the owner's own Google account / 運営者本人のGoogleアカウントのOAuthトークン
  • Basic information about the owner's own YouTube channel (channel ID, title) / 自分のチャンネルの基本情報（チャンネルID、名称）
  • Metadata and statistics of videos on the owner's own channel / 自分のチャンネルの動画のメタデータと統計
  • YouTube Analytics reports for the owner's own channel / 自分のチャンネルのYouTubeアナリティクスのレポート

4. How data is used / 利用目的

Data is used only to upload and manage videos on the owner's channel and to analyze the channel's own performance to improve future videos.

取得したデータは、自分のチャンネルへの動画の投稿・管理と、今後の動画改善のための自チャンネルの分析にのみ使用します。

5. Storage and sharing / 保存と共有

Data and tokens are stored only on the owner's own computer. They are not sold, shared with, or disclosed to any third party.

データとトークンは運営者本人のパソコン内にのみ保存し、第三者への販売・共有・開示は行いません。

6. Retention and deletion / 保存期間と削除

Analytics data is kept only as long as needed for analysis. Stored data and tokens can be deleted at any time by the owner. To request deletion or ask questions, contact nijiupch.contact@gmail.com.

分析データは必要な期間のみ保持し、保存データとトークンは運営者がいつでも削除できます。削除の依頼やお問い合わせは nijiupch.contact@gmail.com までご連絡ください。

7. Revoking access / アクセス権の取り消し

Access granted to the Tool can be revoked at any time from the Google security settings page.

本ツールに付与したアクセス権は、Googleアカウントのセキュリティ設定ページからいつでも取り消せます。

8. Cookies / Cookie

The Tool and this website do not use cookies or tracking technologies.

本ツールおよび本ウェブサイトは、Cookieやトラッキング技術を使用しません。

9. Changes / 改定

This policy may be updated. The latest version is always published on this page.

本ポリシーは改定することがあります。最新版は常にこのページに掲載します。
