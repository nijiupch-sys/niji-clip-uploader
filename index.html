niji-clip-uploader

niji-clip-uploader is an internal tool used only by the owner of the YouTube channel "NIJI-UP-チャンネル [にじさんじ切り抜き]" to manage uploads to that single channel. It is not offered to other users.

niji-clip-uploader は、YouTubeチャンネル「NIJI-UP-チャンネル [にじさんじ切り抜き]」の運営者本人だけが使う、動画投稿管理用の内部ツールです。他のユーザーには提供していません。

What it does / 機能

  • Uploads videos that the channel owner has reviewed and approved / 運営者が確認・承認した動画のアップロード
  • Sets titles, descriptions, thumbnails and scheduled publish times / タイトル・概要欄・サムネイル・予約公開日時の設定
  • Reads the channel's own YouTube Analytics data / 自分のチャンネルのYouTubeアナリティクスの取得

This tool uses YouTube API Services. / 本ツールは YouTube API サービスを使用しています。
